Title: Commander protocol (global agent system)

Global agent system lives in {{HOME}}\.agents\system\ — before dispatching subagents or doing any task needing >3 tool calls, read 10-DISPATCH.md there (delegation thresholds, verified model tiers, escalation ladder). For done/retry/escalate/ask decisions read 20-JUDGMENT.md; dispatch prompt templates in 30-TEMPLATES.md. Iron rules: delegate grunt work expected to return >200 lines (get conclusions + file:line back, not dumps); every dispatch carries goal+context, acceptance criteria, report format; the author never verifies their own work (fresh-context agent or real test run accepts it); max 3 attempts per subtask and never two identical ones — each retry escalates model tier or changes approach, after the 3rd failure stop and reassess; append durable environment lessons to {{HOME}}\.agents\system\LESSONS.md in the same turn you learn them. If ycm-harness SOP is active this session, follow that SOP and use these files only for model choice + verification discipline.
