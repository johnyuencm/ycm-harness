# LESSONS — Hard-won environment facts

This file is a local learning ledger. The installer creates it but never
overwrites an existing copy.

Record only durable, reusable facts learned from actual failures. Keep entries
portable and omit credentials, private identifiers, personal project names,
absolute home paths, temporary ticket IDs, and session transcripts.

## Entry template

### L1 | YYYY-MM-DD | surface | Short title

Trigger: What failed or was unexpectedly costly.

Cost: The concrete impact.

Rule: The smallest durable rule that prevents recurrence.
